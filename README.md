# HQ Construct Website

Premium concept website for HQ Construct, built as a Next.js App Router site.

## Requirements

- Node.js `>=22.13.0`

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Vercel

Use the Next.js app preset.

- Framework preset: `Next.js`
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: leave as Vercel default

The site is a static App Router route and does not require Vite, Vinext, Cloudflare Workers, D1, or Drizzle.
